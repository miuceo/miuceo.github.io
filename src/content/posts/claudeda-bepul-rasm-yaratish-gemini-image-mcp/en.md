🎨 **Gemini Image MCP — a free image generator for Claude**

Did you want to create images directly from Claude but don’t want to pay for a paid API? I wrote an open‑source MCP server that solves this problem.

![](https://github.com/miuceo/gemini-image-mcp/raw/main/assets/logo.png)

## What does it do?

The server works with Gemini’s web app (gemini.google.com) using your account. No paid Gemini API is used, and there’s no charge per image.

## Features

- 🖼 Generate an image from a text description
- ✏️ Edit existing images
- 🔄 Choose one of the Gemini models
- 🗂 All images are stored in a single HTML gallery

## New: automatic login via Firefox 🦊

Now you don’t have to copy cookies manually. You log into Gemini once in Firefox, and the server reads the login data itself. If the session expires, it obtains a new one automatically. Firefox does not need to stay open.

## Who is it for?

Developers, designers, and content creators who work with Claude Code or Claude Desktop. If you need a banner, illustration, or an image for a project, just ask Claude.

> ⚠️ **Note:** this is an unofficial tool. It uses your personal Gemini session, so don’t share your cookies with anyone.
