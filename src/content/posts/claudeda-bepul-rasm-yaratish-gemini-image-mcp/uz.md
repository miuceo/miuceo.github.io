🎨 **Gemini Image MCP — Claude uchun bepul rasm generatori**

Claude'dan to'g'ridan-to'g'ri rasm yaratishni xohlaganmisiz, lekin pullik API uchun to'lashni istamaysizmi? Shu muammoni hal qiluvchi ochiq kodli MCP server yozdim.

![](https://github.com/miuceo/gemini-image-mcp/raw/main/assets/logo.png)

## Bu nima qiladi?

Server Gemini'ning veb ilovasi (gemini.google.com) bilan sizning akkauntingiz orqali ishlaydi. Pullik Gemini API ishlatilmaydi, har bir rasm uchun to'lov ham yo'q.

## Imkoniyatlari

- 🖼 Matnli tavsifdan rasm yaratish
- ✏️ Mavjud rasmlarni tahrirlash
- 🔄 Gemini modellaridan birini tanlash
- 🗂 Barcha rasmlar bitta HTML galereyada saqlanadi

## Yangi: Firefox orqali avtomatik kirish 🦊

Endi cookie'larni qo'lda nusxalash shart emas. Firefox'da Gemini'ga bir marta kirasiz, server esa login ma'lumotlarini o'zi o'qiydi. Sessiya eskirsa, yangisini o'zi oladi. Firefox ochiq turishi ham shart emas.

## Kimlar uchun?

Claude Code yoki Claude Desktop'da ishlaydigan dasturchilar, dizaynerlar va kontent yaratuvchilar uchun. Banner, illyustratsiya yoki loyiha uchun rasm kerak bo'lsa, Claude'ga yozasiz, xolos.
