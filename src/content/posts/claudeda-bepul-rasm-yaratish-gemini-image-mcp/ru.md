🎨 **Gemini Image MCP — бесплатный генератор изображений для Claude**

Хотели создавать изображения напрямую из Claude, но не хотите платить за платный API? Я написал открытый MCP‑сервер, решающий эту проблему.

![](https://github.com/miuceo/gemini-image-mcp/raw/main/assets/logo.png)

## Что это делает?

Сервер работает через веб‑приложение Gemini (gemini.google.com) от вашего аккаунта. Платный Gemini API не используется, оплата за каждое изображение отсутствует.

## Возможности

- 🖼 Создание изображения по текстовому описанию
- ✏️ Редактирование существующих изображений
- 🔄 Выбор одной из моделей Gemini
- 🗂 Все изображения сохраняются в одной HTML‑галерее

## Новое: автоматический вход через Firefox 🦊

Больше не нужно вручную копировать куки. Вы один раз входите в Gemini в Firefox, сервер сам считывает данные входа. Если сессия истекает, он получает новую. Не требуется, чтобы Firefox оставался открытым.

## Для кого?

Для разработчиков, дизайнеров и создателей контента, работающих в Claude Code или Claude Desktop. Если нужен баннер, иллюстрация или изображение для проекта — просто напишите в Claude, и всё.

> ⚠️ **Примечание:** это неофициальный инструмент. Он использует вашу личную сессию Gemini, поэтому никому не передавайте свои куки.
