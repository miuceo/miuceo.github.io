🚀 uv — Python'dagi barcha muammolaringizni yechadigan bitta vosita

Eslang-chi, yangi Python loyihasini boshlash qanday kechardi:

pyenv install 3.13
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt # va 2 daqiqa kutasiz...

To‘rt xil vosita, to‘rt xil konfiguratsiya fayli va oxirida baribir “menda ishlayapti‑ku” muammosi.

uv — Rust’da yozilgan va bularning hammasini bitta o‘zi almashtiradigan vosita. Rasmiy hujjatdagi ta’rif: pip, pip‑tools, pipx, poetry, pyenv, twine, virtualenv — barchasining o‘rniga bitta uv.

Astral (Ruff’ni yaratgan jamoa) ning aytishicha, u pip‑dan 10–100 barobar tezroq (keshi isigan holatda).

⚡️ Boshlash — 3 ta buyruq

uv init myproject
uv add fastapi
uv run main.py

Birinchisi loyiha va src/ tuzilmasini yaratadi, ikkinchisi paketni qo‘shib lock qiladi, uchinchisi ishga tushiradi.

Diqqat qiling: activate yo‘q. uv run virtual muhitni o‘zi topadi, kerak bo‘lsa yaratadi. Men source .venv/bin/activate yozganimga bir necha oy bo‘ldi.

—————

🔥 Eng "hype" imkoniyatlar

1. Python’ning o‘zini ham o‘rnatadi

pyenv endi kerak emas:

uv python install 3.13
uv python pin 3.13

Loyihangizda requires-python = ">=3.13" bo‘lsa va sizda u yo‘q bo‘lsa — uv uni avtomatik yuklab oladi.

2. uvx — o‘rnatmasdan ishlatish

uvx ruff check .
uvx cowsay -t "salom"

Bu npx ning Python’dagi ko‘rinishi. Vaqtinchalik muhitda ishga tushiradi, tizimingizni ifloslantirmaydi.

3. Bitta faylli skriptlar — requirements.txt’siz 🤯

Mening eng sevimli imkoniyatim. Skript faylining o‘ziga bog‘liqliklarni yozasiz (PEP 723 standarti):

/// script

requires-python = ">=3.12"

dependencies = ["requests<3", "rich"]

///

import requests
from rich.pretty import pprint

pprint(requests.get("https://api.github.com").json())

Keyin shunchaki:

uv run script.py

Hammasi tayyor. Virtual muhit yo‘q, pip install yo‘q, hech narsa yo‘q.

Bog‘liqlikni qo‘shish uchun:

uv add --script script.py httpx

Hatto shebang qo‘shsangiz, skript to‘g‘ridan‑to‘g‘ri bajariladigan bo‘ladi:

#!/usr/bin/env -S uv run --script
